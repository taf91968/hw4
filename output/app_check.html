How this was tested

Each screenshot was taken from the running app: the React site at http://localhost:5173, plus the FastAPI backend started from backend/ with uvicorn main:app --reload --port 8000. The agent is the live PydanticAI agent (gpt-5.6-luna via Portkey). A script drove a real Chrome browser (Playwright) like a shopper: it opened pages, clicked buttons and typed into the chat, then waited for the agent's real answer before each screenshot. It browsed as a guest, so nothing was saved to the database. To check honesty, the script also read each product's real price and stock from the database (/api/products/<id>) and compared it with what the chat and the page showed.
